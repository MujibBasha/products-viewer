# 📦 عارض المنتجات

واجهة محلية لعرض **500 منتج** مع زر نسخ سريع لبيانات كل منتج.

## ✨ المميزات

- 🔍 **بحث بالاسم** فوري ومباشر
- 📂 **تصفية حسب الفئة** (مستحضرات تجميل، إلكترونيات، مطبخ، إلخ)
- 💰 **ترتيب حسب السعر** (تصاعدي / تنازلي)
- 🖼️ **عرض الصور** من خادم `api.mdm.express`
- 📋 **زر نسخ** بيانات المنتج كاملةً (الاسم، الوصف، السعر، الكود، الفئة، رابط المنتج، رابط الصورة)
- 🔗 زر فتح رابط المنتج الأصلي
- 🌙 يدعم RTL والعربية بخط Cairo

## 🚀 كيفية التشغيل

بسبب قيود المتصفحات على تحميل ملفات JSON محلياً عبر `file://`، يجب تشغيل خادم محلي بسيط:

### الخيار 1: Python (موصى به)

من داخل مجلد `products-viewer`:

```bash
python -m http.server 8000
```

ثم افتح في المتصفح: <http://localhost:8000>

### الخيار 2: Node.js

```bash
npx serve
```

### الخيار 3: PHP

```bash
php -S localhost:8000
```

## 📁 الملفات

| الملف | الوصف |
|---|---|
| `index.html` | واجهة العرض (HTML + CSS + JS) |
| `products.json` | بيانات الـ500 منتج (376 KB) |
| `README.md` | هذا الملف |

## 📋 صيغة النسخ

عند الضغط على زر "📋 نسخ بيانات المنتج"، يتم نسخ نص بهذا الشكل:

```
اسم المنتج

وصف المنتج كنص نظيف بدون وسوم HTML

💰 السعر: 25 دينار ليبي
🔖 الكود: LSP-XXXXXX
📂 الفئة: المنزل والمطبخ
🔗 رابط المنتج: https://...
🖼️ رابط الصورة: https://api.mdm.express/api/media/01K...
```

## 🔧 ملاحظات تقنية

- الصور تُحمّل بشكل كسول (`lazy loading`) فلا يحدث تباطؤ عند التمرير
- الواجهة كاملة الاستجابة (Responsive) وتعمل على الموبايل والديسكتوب
- يدعم زر النسخ المتصفحات الحديثة (`navigator.clipboard`) مع fallback للقديمة
